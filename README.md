# 🌾 KrishiLink – Grow, Connect & Thrive

**Live Site URL:** [https://assignment-10-46c35.web.app/]

KrishiLink is a modern agriculture-based web platform that connects **farmers, traders, and consumers** in a smart, sustainable, and efficient digital marketplace.  
Built with the **MERN stack**, KrishiLink helps users share crop details, express buying interests, and manage their agricultural activities easily.

---

## 🌟 Key Features

- 🌿 **Dynamic Crop Marketplace:**  
  Farmers can post their crops with detailed information (price, quantity, location, image, and description), and buyers can express interest directly.

- 🔐 **Secure Authentication System:**  
  Private routes and Firebase authentication ensure that only registered users can access protected pages and perform actions like posting or editing crops.

- 📈 **Interactive Dashboard:**  
  Farmers can view, update, or manage their crops and see interests shown by potential buyers in a smooth, data-driven UI.

- 💬 **Interest & Communication System:**  
  Users can show interest in crops, and crop owners can manage these requests using an organized dashboard table.

- 🎨 **Modern Responsive UI with AOS Animations:**  
  Beautiful, mobile-friendly design built using **Tailwind CSS**, **React Icons**, and **AOS animations**, maintaining a consistent green agricultural theme.

---

## ⚙️ Technologies Used

- **Frontend:** React, React Router, Tailwind CSS, DaisyUI, AOS, SweetAlert2  
- **Backend:** Node.js, Express.js, MongoDB  
- **Authentication:** Firebase Authentication  
- **Hosting:** Firebase (Client) & Vercel (Server)

---

## 🚀 How It Works

1. Users sign up or log in securely.  
2. Farmers can post crops with all necessary details.  
3. Buyers can browse and express interest in available crops.  
4. Owners manage received interests directly from their dashboard.  
5. Everyone contributes to a connected and smarter agricultural ecosystem.
